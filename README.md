# wudget

ios spending tracker that makes budgeting fast and glanceable.

## features
- smart expense categorization
- recurring payment tracking
- home-screen widgets
- face id app lock
- shortcuts import

## built with
- swiftui
- swiftdata
- widgetkit
- app intents

## getting started
open `WalletBudget.xcodeproj` in xcode and build to run.
